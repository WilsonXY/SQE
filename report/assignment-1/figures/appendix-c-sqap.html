Software Quality Assurance Plan: Actual Budget

Management

  • Existing roles own the exit policies
  • Triager, implementer, reviewer, release maintainers
  • High tier: independent reviewer (not author, not code owner)

Documentation

  • Written QA plan
  • Risk tier and acceptance criteria per card
  • Design note (High tier)
  • Coverage report; review approval; advisories

Standards, practices and conventions

  • ISO/IEC 25010:2023
  • OWASP ASVS 5.0.0
  • WCAG 2.2 AA
  • IEEE 1012-2024 (risk tiers)
  • Metric: test coverage

Reviews and audits

  • Triage check
  • PR review
  • Design and Verify review (High tier)
  • Release evidence check
  • External security audit (OSTIF)

Test

  • Existing: lint, type check, Vitest, migration check, Playwright E2E and visual, CodeQL
  • Added: coverage, authorisation test matrix, WCAG 2.2 AA checks, regression tests

Problem reporting and corrective action

  • Private vulnerability reporting
  • Coordinated disclosure
  • Open critical or high finding blocks release
  • Escaped defect: regression test, check review, tier review

Risk management and change control

  • Risk tier decides checks
  • Tiers corrected after escaped defects
  • Board → pull request → CI
  • Tools: GitHub, CodeQL, Vitest, Playwright
